the expression "1L << number" means 2 raised to the power of number (2 ** number). The L here is used to allow for greater number of possibilities. If 1 (1 here is an int type) was only used, then using a number above or equal to 31 would result in an undefined behaviour. Because an int type has a limit of 32 bit. Using "L" here means a long type is expected, i.e up to 64bits. Meaning a number can be up to 64.
